# Synopsis

Synopsis is a web application for tracking TV shows.

## Project Description

Synopsis allows users to search for television shows and save them
to a personal library.

The goal is to create an intuitive way for users to organize the
shows they have watched.

Uses JS, Vite and the TVmaze API to run and get TV show data.
